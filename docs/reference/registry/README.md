# Registry domain references

Current contracts for direct operational records. Start with [shared rules](shared-rules.md), then the domain you are changing. Historical proposals and delivery narratives belong to [records](../../records/README.md).

| Domain | Owning reference |
|---|---|
| Identity, animal events and calving | [Animals](animals.md) |
| Per-animal session measurement | [Milking](milking.md) |
| Dispatch, buyers, rates and balances | [Sales](sales.md) |
| People, engagements, wages and payments | [Payroll](payroll.md) |
| Crops, purchases and daily feeding | [Feed](feed.md) |
| Visits, treatment, vaccination and lifetime reports | [Health](health.md) |
| Production, coverage and reconciliation metrics | [Analytics](analytics.md) |

[Application interactions](../ui/application-interactions.md) owns shared navigation/draft behavior. [Assistant tools](../integrations/assistant-tools.md) describe the read-only registry boundary; they do not replace these HTTP contracts.

[HTTP route reference](http-api.md) is checked against registered routes by the server suite.
